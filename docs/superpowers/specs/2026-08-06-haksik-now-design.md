## 1. 컨셉

> 지금 어느 학식이 한가한지 실시간으로 보고, 붐비기 전에 원하는 메뉴를 바로 주문하는 모바일 웹.

학교생활 편의 앱. 핵심 가치는 **줄 서기·대기시간 문제 해소**와 **주문 방식의 간편화**. (공익 프레이밍은 이번 범위에서 다루지 않음 — 캠퍼스 편의성으로 충분하다고 판단.)

## 2. 범위 (Scope)

### 포함 (In scope)
- 식당별 실시간 혼잡도 현황판
- 오늘의 메뉴 조회
- '지금 주문' (즉시 주문 → 주문번호 발급)

### 제외 (Out of scope — 명시적으로 뺌)
- 선주문 (advance order)
- 픽업 시간 예약
- 실제 결제/PG 연동
- 로그인·회원가입·사용자 계정
- 백엔드 서버·데이터베이스
- 혼잡도 크라우드소싱 제보 (선택적 확장 후보로만 남김)

---

## 3. 화면 구성 (총 3개)

### 화면 1 — 메인: 실시간 혼잡도 현황판
- 식당(구역)별 카드 목록.
- 각 카드에 혼잡도 신호등: `여유 🟢 / 보통 🟡 / 혼잡 🔴`.
- 예상 대기 인원 및 예상 대기 시간 표시.
- 몇 초마다 혼잡도 값이 조금씩 변동해 "실시간" 느낌 제공.
- 카드 탭 → 화면 2로 이동.

### 화면 2 — 식당 상세 / 메뉴
- 선택한 식당의 오늘 메뉴·가격 목록.
- 시간대별 혼잡도 그래프(막대/라인) — 언제 한가한지 한눈에.
- "주문하기" 버튼 → 화면 3으로 이동.

### 화면 3 — 주문
- 메뉴 담기(장바구니).
- **"지금 주문"** 버튼 → 즉시 주문 처리 (픽업 시간 선택 없음).
- 주문 완료 시 주문번호 + 가짜 QR 표시.
- 목업 결제 — 실제 돈은 나가지 않음.

---

## 4. 데이터 & "실시간" 처리 (전부 목업)

- 백엔드·DB·로그인 **전부 없음**. 모든 데이터는 프론트엔드 JS 상수로 관리.
- **혼잡도 데이터 구조 (예시)**:
  ```
  식당: { id, 이름, 혼잡도(0~100), 대기인원, 예상대기분, 오늘메뉴[], 시간대별혼잡[] }
  메뉴: { id, 이름, 가격, 품절여부 }
  ```
- **실시간 느낌**: `setInterval`로 각 식당의 혼잡도 값을 몇 초마다 소폭 무작위 변동 → 신호등/대기 인원이 화면에서 살아 움직임.
- **주문 상태**: 브라우저 `localStorage`에 저장 → 새로고침해도 유지.
- **(선택 확장)** "혼잡도 제보" 버튼: 심사위원이 눌러 현황판이 즉시 바뀌는 걸 체험. 시간이 남을 때만 추가.

## 5. 기술 스택 (AI 코딩 도구 전제)

- **React 단일 페이지 앱 (Vite 기반)** — 또는 v0 / Bolt로 초안 생성 후 조정.
- **Vercel 무료 배포** (또는 로컬 실행).
- 서버·DB 없음 → 비전공자가 막히기 쉬운 지점(배포, API 키, CORS, 인증)을 원천 제거.
- 팀은 AI 코딩 도구(Claude, Cursor, v0 등)로 코드 생성 → 조정 방식으로 진행.

## 6. 역할 분담 (3인)

- **A**: 메인 혼잡도 현황판 + 실시간 변동 로직
- **B**: 메뉴 화면 + 주문 흐름 + localStorage
- **C**: 디자인/스타일 통일 + 발표자료 + 시연 시나리오

## 6-1. 협업 워크플로우

1. **뼈대(스캐폴드) 생성**: 한 명이 React(Vite) 기본 프로젝트 + 3개 화면의 빈 컴포넌트 + 공용 목업 데이터 파일을 만든다.
2. **GitHub 저장소 업로드**: 뼈대를 GitHub 저장소에 올리고(초기 커밋 + push), 팀원 2명을 협업자(collaborator)로 초대한다.
3. **역할 분담 확정**: 아래 7절 역할대로 각자 담당 화면/기능을 정한다.
4. **분업 진행**: 각자 브랜치(또는 담당 파일)로 작업 → 수시로 push/merge하여 통합.

> 비전공자 팀 기준 권장: 파일 충돌을 줄이기 위해 화면별 파일을 분리하고, 공용 목업 데이터는 초반에 확정해 이후 변경을 최소화한다.

## 8. 성공 기준 (Definition of Done)

- 메인에서 식당별 혼잡도가 시각적으로 구분되고, 화면에서 값이 실시간으로 변동한다.
- 식당 상세에서 오늘 메뉴와 시간대별 혼잡도를 볼 수 있다.
- 메뉴를 담아 "지금 주문"하면 주문번호가 발급되고, 새로고침해도 주문 내역이 유지된다.
- 모바일 화면 폭에서 자연스럽게 보인다 (모바일 웹 우선).
- 배포된 URL(또는 로컬)에서 3분 내 전체 흐름 시연이 가능하다.
