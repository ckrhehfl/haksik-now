## 3. 주문 저장 형식 (localStorage)

주문은 서버가 없으니 브라우저에 저장합니다. 팀원2가 사용:

```js
// 저장 키: "haksik_orders"
// 저장 값: 아래 형태의 배열(JSON)
{
  orderNo: "A1234",              // 주문번호 (아래 규칙으로 생성)
  restaurantId: "r1",
  restaurantName: "학생식당",
  items: [ { id: "m1", name: "제육덮밥", price: 4500, qty: 1 } ],
  total: 4500,
  createdAt: "2026-08-06T12:00:00.000Z"
}

// 주문번호 생성 규칙:
const orderNo = "A" + Date.now().toString().slice(-4);
```

## 4. 라우팅(주소) 규칙

`App.jsx`에서 react-router-dom으로 연결 (팀원1이 만듦). 주소는 아래로 고정:

| 주소 | 화면 | 담당 |
|---|---|---|
| `/` | 혼잡도 현황판 (HomePage) | 팀원1 |
| `/restaurant/:id` | 식당 상세/메뉴 (RestaurantPage) | 팀원2 |
| `/order/:id` | 메뉴 담기+지금주문 (OrderPage) | 팀원2 |
| `/order-complete` | 주문완료 (OrderCompletePage) | 팀원2 |

화면 이동은 `useNavigate()`의 `navigate("/restaurant/r1")` 형태로 합니다.

## 6. git 사용법 (초보용, 이것만 외우세요)

**작업 시작 전 — 항상 최신 받기:**
```bash
git pull
```

**작업 끝나면 — 올리기 (3줄):**
```bash
git add .
git commit -m "무엇을 했는지 한글로 짧게"
git push
```

**충돌(conflict)이 나면** 당황 말고 단톡에 "충돌났어요" 공유 → 리더가 함께 해결.
**충돌 예방:** ①시작 전 `git pull` ②자기 담당 파일만 수정 ③작업 끝나면 바로 push.

## 7. AI에게 시킬 때 공통 팁

- **Claude Code**(파일을 직접 만들어주는 도구): 프롬프트를 그대로 붙여넣으면 파일을 생성/수정해 줍니다. 끝나면 `npm run dev`로 확인.
- **Gemini 채팅창**(코드를 글로 주는 곳): 프롬프트를 붙여넣으면 코드가 나옵니다. 그 코드를 복사해 해당 파일에 붙여넣고 저장하세요.
- 두 경우 모두, 결과가 이상하면 **"이 부분이 이렇게 안 돼. 이렇게 고쳐줘"** 라고 이어서 말하면 됩니다.
- 항상 확인: 저장 후 `npm run dev` 화면에서 내 화면이 보이는가?
