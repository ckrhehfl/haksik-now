## 3. 주문 저장 형식 (localStorage)

주문은 서버가 없으니 브라우저에 저장합니다. 팀원2가 사용:

```js
// 저장 키: "haksik_orders"
// 저장 값: 아래 형태의 배열(JSON)
{
  orderNo: "A1234",              // 주문번호 (아래 규칙으로 생성)
  restaurantId: "r1",
  restaurantName: "학생식당",
  items: [ { id: "m1", name: "제육덮밥", price: 4500, qty: 1 } ],
  total: 4500,
  createdAt: "2026-08-06T12:00:00.000Z"
}

// 주문번호 생성 규칙:
const orderNo = "A" + Date.now().toString().slice(-4);
```

## 4. 라우팅(주소) 규칙

`App.jsx`에서 react-router-dom으로 연결 (팀원1이 만듦). 주소는 아래로 고정:

| 주소 | 화면 | 담당 |
|---|---|---|
| `/` | 혼잡도 현황판 (HomePage) | 팀원1 |
| `/restaurant/:id` | 식당 상세/메뉴 (RestaurantPage) | 팀원2 |
| `/order/:id` | 메뉴 담기+지금주문 (OrderPage) | 팀원2 |
| `/order-complete` | 주문완료 (OrderCompletePage) | 팀원2 |

화면 이동은 `useNavigate()`의 `navigate("/restaurant/r1")` 형태로 합니다.

## 6. git 사용법 (초보용, 이것만 외우세요)

**작업 시작 전 — 항상 최신 받기:**
```bash
git pull
```

**작업 끝나면 — 올리기 (3줄):**
```bash
git add .
git commit -m "무엇을 했는지 한글로 짧게"
git push
```

**충돌(conflict)이 나면** 당황 말고 단톡에 "충돌났어요" 공유 → 리더가 함께 해결.
**충돌 예방:** ①시작 전 `git pull` ②자기 담당 파일만 수정 ③작업 끝나면 바로 push.

## 7. Claude Code로 작업하는 법 (우리 팀 공통 도구)

우리는 **전부 Claude Code(터미널 CLI)**로 작업합니다. Claude가 파일을 직접 만들고 고쳐줍니다.

**기본 순서 (이것만 외우세요):**

1. 프로젝트 폴더에서 터미널을 열고 Claude Code를 실행:
   ```bash
   cd haksik-now
   claude
   ```
2. 내 카드에 있는 **프롬프트를 그대로 붙여넣고 엔터.** → Claude가 해당 파일을 만들어/고쳐 줍니다.
3. 파일 수정을 승인(허용)합니다.
4. 다른 터미널(또는 새 터미널)에서 화면 확인:
   ```bash
   npm run dev
   ```
5. 결과가 이상하면 Claude에게 이어서 말하세요:
   > "npm run dev에서 이런 에러가 나: (에러 메시지 붙여넣기). 고쳐줘"
   > 또는 "이 부분이 이렇게 안 돼. 이렇게 고쳐줘"

**팁**
- Claude Code는 프로젝트 파일을 스스로 읽으니, 프롬프트에 파일 경로만 정확히 있으면 됩니다(카드에 이미 적혀 있음).
- **카드 통째로 맡기기도 가능:** `claude`에서 **"docs/superpowers/plans/team/내카드.md 를 읽고 3번 프롬프트를 순서대로 진행해줘"** 라고 하면 Claude가 알아서 순서대로 만들어 줍니다. (프롬프트를 하나씩 붙여넣는 대신 써도 됨)
- 한 파일이 끝나면 `git push` 하고 다음 프롬프트로 넘어가세요.
- 항상 확인: 저장 후 `npm run dev` 화면에서 내 화면이 보이는가?
