## 3. Claude Code에 붙여넣을 프롬프트 (순서대로 4개)

> 프로젝트 폴더에서 `claude`를 실행한 뒤, 아래 프롬프트를 하나씩 붙여넣으세요. (실행법은 00-공용규칙.md 7번)

### 프롬프트 ①: 공용 스타일

```
React + Vite 앱의 공용 스타일 src/index.css를 만들어줘. 모바일 우선 학식 앱이야.

- 전체 배경 #f9fafb, 기본 글꼴은 시스템 기본 산세리프.
- body 안 콘텐츠는 최대 폭 480px, 가운데 정렬.
- 주 색상 #2563eb(파랑). 버튼은 이 색 배경 + 흰 글씨 + 둥근 모서리(10px) + 눌리는 느낌.
- .card 클래스: 흰 배경, 둥근 모서리 12px, 옅은 그림자, 안쪽 여백 16px, 카드 사이 간격.
- 혼잡도 색 변수: --green:#22c55e; --orange:#f59e0b; --red:#ef4444;
- 링크/버튼 커서 pointer. 깔끔하고 요즘 앱 같은 느낌으로.
```

### 프롬프트 ②: 공용 상단바

```
React로 src/components/Header.jsx를 만들어줘.
- 앱 이름 "학식 나우"를 가운데(또는 왼쪽)에 보여주는 심플한 상단바.
- 주 색상 #2563eb 배경에 흰 글씨, 모바일 폭에 맞게.
- 클릭하면 메인("/")으로 가도록 react-router-dom의 Link 사용.
다른 팀원이 각 페이지 맨 위에서 <Header /> 로 불러 쓸 수 있게 export.
```

### 프롬프트 ③: 혼잡도 배지 컴포넌트 (팀원1·2가 재사용)

```
React로 src/components/CongestionBadge.jsx를 만들어줘.
- props로 congestion(0~100 숫자)를 받아.
- src/data/mockData.js의 congestionLevel(congestion)을 import해서 {label, color, emoji}를 얻고,
- 작은 알약(pill) 모양 배지로 "🟢 여유" 처럼 이모지+라벨을 보여줘. 배경/글씨색에 color를 은은하게 적용.
export default로 내보내서 <CongestionBadge congestion={35} /> 처럼 쓸 수 있게.
```

> 만든 뒤 팀원1·2에게 "혼잡도 배지 컴포넌트 올렸어요, `<CongestionBadge congestion={식당.congestion} />`로 쓰면 돼요" 공유.

### 프롬프트 ④: 반응형 점검 (통합 단계에서)

```
지금 이 React 학식 앱을 아이폰 폭(약 390px)에서 봤을 때 요소가 넘치거나 너무 작지 않게 CSS를 점검·수정해줘.
카드 간격, 버튼 크기(손가락으로 누르기 좋게 최소 44px 높이), 글자 크기를 모바일에 맞게 다듬어줘.
```

## 4. 발표자료 + 시연 시나리오 (막판 2시간)

발표 슬라이드(구글 슬라이드/PPT)를 6장으로:

1. **제목** — "학식 나우: 줄 서지 않는 학식"
2. **문제** — 점심 피크 긴 줄, 헛걸음, 대기 스트레스 (사진/숫자 1~2개)
3. **해결** — 실시간 혼잡도로 한가한 식당 찾고, 붐비기 전에 바로 주문
4. **시연** — 라이브 데모 (아래 시나리오)
5. **어떻게 만들었나** — React + 목업 데이터, 12시간, 3인 분업 (한 줄씩)
6. **다음 단계** — 실제 식당 연동, 결제, 혼잡도 제보 기능

**시연 시나리오(3분, 리허설 필수):**
1. 메인에서 식당 3개 혼잡도 보여주기 → 숫자가 실시간으로 바뀌는 것 강조.
2. "여유🟢"인 식당 눌러 상세 → 메뉴 + 시간대별 그래프.
3. 메뉴 담고 "지금 주문" → 주문번호 화면.
4. 새로고침해도 주문 남는 것 보여주기.
