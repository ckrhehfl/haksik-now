### 프롬프트 ①: 공용 데이터 파일 만들기 (⚠️ 이미 완료 — 건너뛰세요)

> `src/data/mockData.js`는 이미 실제 학식 메뉴(5개 점포 × 3개)로 저장소에 있습니다. **아래 프롬프트는 참고용**이며, 다시 만들 필요 없습니다. 바로 프롬프트 ③(HomePage)으로 가세요.

```
React + Vite 프로젝트에서 학식 앱의 목업 데이터 파일을 만들어줘.
파일 경로: src/data/mockData.js

아래 형식 그대로, 식당 3개(학생식당/교직원식당/기숙사식당)와 각 식당의 메뉴 2~3개를 담아줘.

- restaurants 라는 이름으로 export하는 배열
- 각 식당: { id, name, congestion(0~100), waitingCount, waitMinutes, hourly(7개 숫자 배열), menus[] }
- 각 메뉴: { id, name, price, soldOut }
- 그리고 congestionLevel(c) 함수도 export: c<40이면 {label:"여유", color:"#22c55e", emoji:"🟢"}, c<70이면 {label:"보통", color:"#f59e0b", emoji:"🟡"}, 그 외 {label:"혼잡", color:"#ef4444", emoji:"🔴"} 를 반환.

한국어 메뉴 이름(제육덮밥, 김치찌개 등)과 4000~5500원 가격으로 채워줘.
```

> 만든 뒤 **바로 push**: `git add . && git commit -m "공용 목업 데이터 추가" && git push`
> 단톡에 "mockData 올렸어요, pull 받으세요" 공유.

### 프롬프트 ②: 라우팅 연결

```
React Router(react-router-dom)로 src/App.jsx를 만들어줘. 아래 4개 주소를 연결해줘:
- "/" → src/pages/HomePage.jsx
- "/restaurant/:id" → src/pages/RestaurantPage.jsx
- "/order/:id" → src/pages/OrderPage.jsx
- "/order-complete" → src/pages/OrderCompletePage.jsx

아직 HomePage 말고 다른 페이지 파일이 없다면, 각 파일에 "준비중"이라고만 표시하는 임시 컴포넌트를 함께 만들어줘.
main.jsx에서 BrowserRouter로 App을 감싸는 것도 처리해줘.
```

### 프롬프트 ③: 메인 현황판 + 실시간 로직

```
React로 src/pages/HomePage.jsx를 만들어줘. 학식 실시간 혼잡도 현황판이야.

- src/data/mockData.js 에서 restaurants 배열과 congestionLevel 함수를 import 해서 사용.
- 화면 상단에 "학식 나우" 제목.
- 식당마다 카드 한 개: 식당 이름, congestionLevel(congestion)로 얻은 신호등 이모지와 등급 라벨(색 적용), "대기 OO명 · 약 OO분" 표시.
- 카드를 클릭하면 useNavigate로 `/restaurant/식당id` 로 이동.
- ⭐실시간 느낌: useState로 식당 데이터 복사본을 들고, useEffect + setInterval(3초)로 각 식당 congestion을 -8~+8 랜덤 변동(0~100 범위로 제한)시키고, waitingCount/waitMinutes도 혼잡도에 비례해 살짝 바꿔줘. 컴포넌트 언마운트 시 clearInterval.
- 모바일 폭(최대 480px 가운데 정렬) 기준으로 보기 좋게. 스타일은 인라인 style 또는 간단한 className으로.
```
