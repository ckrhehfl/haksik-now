## 3. Claude Code에 붙여넣을 프롬프트 (순서대로 3개)

> 프로젝트 폴더에서 `claude`를 실행한 뒤, 아래 프롬프트를 하나씩 붙여넣으세요. (실행법은 00-공용규칙.md 7번)

### 프롬프트 ①: 식당 상세 + 메뉴 + 혼잡 그래프

```
React로 src/pages/RestaurantPage.jsx를 만들어줘. 학식 식당 상세 화면이야.

- react-router-dom의 useParams로 주소의 :id (예: r1)를 읽어와.
- src/data/mockData.js 에서 restaurants 배열과 congestionLevel 함수를 import 해서, id가 일치하는 식당 하나를 찾아 보여줘.
- 상단: 식당 이름 + 현재 혼잡도 신호등(congestionLevel 사용).
- "오늘의 메뉴": menus 배열을 목록으로. 이름·가격 표시. soldOut이 true면 "품절" 회색 처리.
- "시간대별 혼잡도": hourly 배열(11시~17시, 7개 값)을 간단한 세로 막대그래프로. 값이 클수록 막대가 높고, congestionLevel 색을 적용.
- 하단에 "주문하기" 버튼 → useNavigate로 `/order/식당id` 이동.
- 모바일 폭(최대 480px 가운데 정렬) 기준.
```

### 프롬프트 ②: 메뉴 담기 + 지금 주문

```
React로 src/pages/OrderPage.jsx를 만들어줘. '지금 주문' 화면이야. (선주문/픽업시간 예약은 없음)

- useParams로 :id를 읽어 mockData.js의 restaurants에서 해당 식당을 찾음.
- 그 식당의 menus를 목록으로 보여주고, 각 메뉴에 수량 +/- 버튼. soldOut 메뉴는 담기 불가.
- 담은 메뉴들의 합계 금액(total)을 하단에 표시.
- "지금 주문" 버튼을 누르면:
  1) 주문번호 생성: const orderNo = "A" + Date.now().toString().slice(-4);
  2) 아래 객체를 만들어 localStorage 키 "haksik_orders" 배열에 추가(기존 것 유지):
     { orderNo, restaurantId, restaurantName, items:[{id,name,price,qty}], total, createdAt: new Date().toISOString() }
  3) 방금 주문번호를 localStorage "haksik_last_order"에도 저장.
  4) useNavigate로 "/order-complete"로 이동.
- 담은 메뉴가 하나도 없으면 버튼 비활성화.
- 모바일 폭(최대 480px 가운데 정렬) 기준.
```

### 프롬프트 ③: 주문 완료 화면

```
React로 src/pages/OrderCompletePage.jsx를 만들어줘.

- localStorage "haksik_last_order"에서 방금 주문번호를 읽어와 크게 표시("주문번호 A1234").
- localStorage "haksik_orders"에서 그 주문의 상세(식당명, 담은 메뉴, 합계)를 찾아 보여줘.
- 가짜 QR 코드처럼 보이는 사각형(검은 점 패턴이나 단순 도형)을 CSS로 그려 넣어줘. 실제 QR일 필요 없음.
- "새 주문하기" 버튼 → useNavigate로 "/"(메인)로 이동.
- 새로고침해도 주문번호가 그대로 보이는지가 중요(localStorage에서 읽으니 유지됨).
- 모바일 폭(최대 480px 가운데 정렬) 기준.
```

## 4. 되는지 확인 (눈으로 체크)

- [ ] 메인에서 식당 카드를 누르면 상세 화면에 메뉴와 막대그래프가 보인다.
- [ ] "주문하기" → 메뉴 수량을 올리면 합계가 바뀐다.
- [ ] "지금 주문" → 주문번호가 나오는 완료 화면으로 넘어간다.
- [ ] 완료 화면에서 **새로고침해도** 주문번호가 남아있다.
- [ ] 품절 메뉴는 담기지 않는다.
